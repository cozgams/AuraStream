# AuraStream v0.1.1

> **This App Created by AAA**  
> Official release `v0.1.1` (`0.1.1` / Android versionCode `3000101`).

### What's New & Improvements in v0.1.1

1. **Brand-Aligned Release Assets**:
   - Replaced legacy naming across all package targets.
   - Windows portable bundle: `AuraStream_0.1.1_x64_portable.zip`.
   - macOS DMG bundle: `AuraStream_0.1.1_universal.dmg` (Universal binary supporting Apple Silicon and Intel).
   - Linux Debian bundle: `AuraStream_0.1.1_amd64.deb`.
   - Windows installer: `AuraStream_0.1.1_x64-setup.exe`.
   - Android multi-ABI split APKs: `AuraStream_0.1.1_arm64.apk`, `AuraStream_0.1.1_arm.apk`, `AuraStream_0.1.1_x86_64.apk`, and `AuraStream_v0.1.1_universal.apk`.
   - iOS bundle: `AuraStream_0.1.1_ios.ipa`.

2. **Player Stacking Context & Touch Interaction Polish**:
   - Elevated center Play button to `z-20` above the video rendering surface to prevent pointer intercept collision during initial load.
   - Elevated inline player controls to `z-20` ensuring responsive seekbar dragging and click handling.

3. **CI/CD Reliability & Test Hardening**:
   - Streamlined Playwright browser toolchain installation directly via CDN without fragile apt font mirror dependencies.
   - Hardened `api-loading` test suite regex matching for whitespace tolerance.
   - All 9 core regression test suites verified and passing 100%.

4. **Closed Captions & Fine-Tuning**:
   - Confirmed instant live-updating CC vertical slider and 4 quick presets (Downside 12%, Above Title 32%, Middle 50%, Top 85%).
   - Multi-layer subtitle styling and English localized UI.
