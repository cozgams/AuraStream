# AuraStream v0.1 (Build 0.1.0) Official Release

**This App Created by AAA**

### What's New in v0.1:
- **Clean, Streamlined Player UI**: Removed clashing centered overlays and eliminated collisions between Skip Intro and player controls; generous status bar clearance for top controls.
- **Customizable Subtitles & CC Position**: Choose between 4 quick presets (Downside, Above Title, Middle, Top) or use the fine-grained custom vertical slider (5% to 90%) to place subtitles anywhere on screen, paired with customizable typography scales and styles (Netflix Yellow, Classic White, Cinema Cyan).
- **Default Download Quality Selector**: Added dedicated codec preference in Settings (Auto, HEVC, H.264) for maximum offline efficiency and bandwidth optimization.
- **Refined Downloads Tab & File Sizes**: Direct episode cards showing prominent file sizes (e.g. 14.5 MB), instant playback, MP4 export, and zero auto-deletion.
- **Floating In-App Download Banner**: Real-time speed (MB/s), downloaded bytes progress bar, and completion watch alerts.
- **Complete English Localization & Diagnostics**: Full English labels across Settings, Streaming Source, Auto-Select Line, Network Diagnostics, and Playback Diagnostics.
- **Cross-Platform Support**: Android (Universal, ARM64, x86_64), Windows, macOS, and Linux.
