# AuraStream v0.1.3

> **This App Created by AAA**  
> Official release `v0.1.3` (`0.1.3` / Android versionCode `3000103`).

### What's New & Improvements in v0.1.3

1. **Parser & Dual-Track Subtitle Fidelity**:
   - In `vttParser.ts`, preserved original Chinese transcript cues (`zh`) alongside normalized English translations (`en`) instead of replacing original Chinese cues with English translations.
   - Guaranteed multi-source subtitle cue safety and fallback consistency.

2. **Download Group Size Null-Safety**:
   - In `Profile.tsx`, added nullish coalescence `(item.sizeBytes || 0)` to series aggregation logic, preventing potential `NaN` corruption in offline storage calculation if an upstream metadata record omitted a byte payload.

3. **Episode Selector Accessibility & Form Safety**:
   - In `BatchDownloadSheet.tsx`, added explicit `type="button"` and `aria-label={`Episode ${ep}`}` to all episode grid buttons, preventing accidental form submission triggers in modal containers and improving screen reader navigation.

4. **Synchronized Multi-Target Release**:
   - Windows installer (`.exe`) & portable (`.zip`)
   - macOS Universal DMG (Apple Silicon + Intel)
   - Linux Debian (`.deb`)
   - Android split APKs (`arm64`, `arm`, `x86_64`)
   - iOS unsigned IPA
