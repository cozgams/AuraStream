# AuraStream v0.1.12

> **This App Created by AAA**  
> Official release `v0.1.12` (`0.1.12` / Android versionCode `3000112`).

### What's New & Improvements in v0.1.12

1. **Subtitle Ergonomics & Android System Navigation Safe Clearance**:
   - Subtitles in clean and full-screen modes now enforce safe clearance above the Android 3-button system navigation bar (48px safe bottom inset). Subtitle text never renders behind back, home, or recent buttons.
   - Fixed letterboxed aspect ratio video calculations to prevent subtitles from dipping below the navigation bar.

2. **Player Right Action Rail Collision Elimination & Touch Responsiveness**:
   - Subtitle overlay automatically applies safe right-side padding (`pr-16 pl-3`) and adjusts container width constraints (`max-w-[72%]`) whenever the right action rail is visible.
   - Long translations, multi-line captions, and fast dialogues no longer overlap or collide with favorite, comment, download, share, and more action buttons.
   - Hardened touch event handling (`onTouchEnd`, `touchAction: manipulation`, `onPointerDown stopPropagation`) across all action rail buttons (Star, Comments, Download, Share, Options) so taps are instantaneous and never intercepted by background video swipe gestures.

3. **System Navigation Bar Clearance for Bottom Sheets & Forms**:
   - Updated `DownloadChoiceSheet`, `BatchDownloadSheet`, `ExportSheet`, `SubtitleSheet`, and comment submission forms to enforce bulletproof safe bottom insets (`max(var(--sab), 48px)`).
   - Action buttons such as "Download Episodes", "Export", and "Send Comment" remain fully accessible and comfortable to tap above the Android system buttons.

4. **Modal Layering Isolation & Clean Sheet Rendering**:
   - Fixed modal backdrop and sheet stacking context using `position: fixed` and isolated `.hg-tabbar` / `.ios-mobile-nav` visibility during active overlay sheets, preventing TabBar bleed-through behind auth and settings sheets.

5. **Profile Header Alignment & Downloads Studio Polish**:
   - Restructured Profile top navbar to vertically center the "Profile" title, "RAM Boost" optimizer, and Settings gear button with precise safe area insets, eliminating button overflow across the separator border.
   - Streamlined series collapse/expand accordion ergonomics with clean state tracking, allowing rapid single-tap show toggling and instant offline playback.
   - Optimized bottom breathing room for the quiet handcrafted footer branding.
