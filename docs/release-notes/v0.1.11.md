# AuraStream v0.1.11

> **This App Created by AAA**  
> Official release `v0.1.11` (`0.1.11` / Android versionCode `3000111`).

### What's New & Improvements in v0.1.11

1. **Complete Profile Tab Redesign & Visual Hierarchy Overhaul**:
   - Redesigned the Profile hero section with clean, flagship mobile ergonomics: elevated card container, online/offline status pill, account metadata, and instant RAM Booster action.
   - Removed duplicate 4-column counter rows in favor of an integrated interactive Segmented Control with live numerical badges (`Favorites`, `Watch Later`, `History`, `Downloads`).
   - Unified surface styling across cards, lists, and headers with consistent rounded geometry (`rounded-2xl`, `rounded-xl`) and subtle border delineation.

2. **Downloads Studio & Offline Library Ergonomics**:
   - Transformed the Downloads view into an offline media hub: shows total series count, episode totals, and combined disk usage.
   - Added collapsible drama series cards with high-contrast poster artwork, instant Episode 1/resume play button, and expand/collapse chevrons.
   - Redesigned episode rows with dedicated green circular play controls, clear episode numbering, file size metrics, and isolated export and deletion actions.
   - Enhanced multi-select bulk operations: added a floating action bar with instant `Export Selected` and `Delete Selected` triggers.

3. **Collections Sub-Header & Empty States Safe Insets**:
   - Moved destructive/bulk actions (`Clear Favorites`, `Clear History`, `Download All Watch Later`) from the bottom of the scroll container to clean, accessible sub-headers at the top of each collection.
   - Fixed vertical centering for empty states across all tabs, adjusting bottom scroll padding so the `Explore Now` button is never obscured by the floating mobile navigation bar.

4. **1-Tap RAM Booster & Deep Memory Purge Integration**:
   - Added direct 1-tap memory optimization to the top navigation bar and hero storage summary card.
   - Flushes preloaded video segment buffers, evicts unneeded manifests, clears AI subtitle memory caches, and frees WebView RAM with real-time freed-memory toast notifications.
