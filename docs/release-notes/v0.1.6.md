# AuraStream v0.1.6

> **This App Created by AAA**  
> Official release `v0.1.6` (`0.1.6` / Android versionCode `3000106`).

### What's New & Improvements in v0.1.6

1. **Comprehensive Desktop & TV Keyboard Shortcuts Suite**:
   - Added standard industry playback controls across all desktop builds (Windows, macOS, Linux) and keyboard-equipped Android tablets / TVs:
     - <kbd>Space</kbd> / <kbd>K</kbd>: Toggle Play / Pause.
     - <kbd>J</kbd> / <kbd>L</kbd>: Universal 10-second Seek Backward / Forward with dynamic HUD ripple indicator.
     - <kbd>←</kbd> / <kbd>→</kbd>: 5-second Seek Backward / Forward.
     - <kbd>P</kbd> / <kbd>N</kbd> / <kbd>↑</kbd> / <kbd>↓</kbd>: Previous / Next Episode.
     - <kbd>C</kbd>: Instant Closed Captions / Subtitle toggle (`English` <-> `Off`) with toast status.
     - <kbd>V</kbd>: AI English Voice Dubbing toggle with toast status.
     - <kbd>F</kbd>: Fullscreen toggle.
     - <kbd>T</kbd>: Theater Mode toggle.
     - <kbd>M</kbd>: Mute / Unmute toggle.
     - <kbd>S</kbd>: Star & Favorite current drama.
     - <kbd>0</kbd> – <kbd>9</kbd>: Instant jump to 0% – 90% of drama duration.
     - <kbd>&lt;</kbd> / <kbd>&gt;</kbd>: Decrease / Increase playback speed (0.75x, 1x, 1.25x, 1.5x, 2x).
     - <kbd>?</kbd>: Open the interactive **Keyboard Shortcuts Guide** modal.

2. **Keyboard Shortcuts Help Modal & In-App Discovery**:
   - Integrated a modal guide accessible via <kbd>?</kbd> or through the *Playback Options* sheet.

3. **Feed Key Interception Fix in Shell**:
   - Prevented global top-level navigation from intercepting numeric keys (`1`..`4`) during active drama playback, ensuring number keys seek smoothly through episodes.

4. **Synchronized Multi-Platform Release**:
   - Full automated builds across Android (`arm64-v8a`, `armeabi-v7a`, `x86_64`), Windows (`NSIS` & portable `ZIP`), macOS (Universal `DMG`), Linux (`DEB`), and iOS (`IPA`).
