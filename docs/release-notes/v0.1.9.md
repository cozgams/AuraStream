# AuraStream v0.1.9

> **This App Created by AAA**  
> Official release `v0.1.9` (`0.1.9` / Android versionCode `3000109`).

### What's New & Improvements in v0.1.9

1. **Authenticated GitHub Release & OTA Update Engine**:
   - Fixed update checker for private GitHub repository (`cozgams/AuraStream`).
   - Added `get_with_auth` in Rust networking core to authenticate GitHub API calls, eliminating 404 responses.
   - Accurately reports new version availability, release notes, and targets architecture-matched APKs.

2. **Native Android Double-Tap Exit & Hardware Back Reliability**:
   - Added dedicated `app_exit` Tauri command in Rust backend (`api::app_exit`) mapped directly to `app.exit(0)`.
   - Android back button gracefully dismisses sheets -> modal -> navigation stack -> double-tap exit on Home tab.

3. **Battery & Screen WakeLock Lifecycle Optimization**:
   - Implemented proper `WakeLockSentinel` tracking and cleanup in video player.
   - Screen stays awake during active playback and automatically releases lock upon pause, finish, or backgrounding to prevent battery drain.

4. **Android WebView HTML5 Inline Playback**:
   - Added standard `playsinline="true"` alongside `webkit-playsinline` on video surface to ensure Android WebViews never hijack playback into system player overlay.
