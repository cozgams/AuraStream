# AuraStream v0.1.8

> **This App Created by AAA**  
> Official release `v0.1.8` (`0.1.8` / Android versionCode `3000108`).

### What's New & Improvements in v0.1.8

1. **Pure Android-First Focus**:
   - Streamlined release workflow ([`.github/workflows/release.yml`](file:///data/home/Project/A/HGhubX/.github/workflows/release.yml)) to focus exclusively on Android native compilation and packaging.
   - Eliminates desktop build queues to deliver faster, leaner APK release pipelines.

2. **Clean Mobile-First Player Controls**:
   - Removed desktop-specific shortcut overlays and extra hotkey suites, restoring clean mobile gesture ergonomics.
   - Mobile touch interactions (double-tap seek, pinch-to-zoom, vertical episode swiping, brightness/volume edge scrubbing) remain silky smooth.

3. **Android Release Keystore Integration**:
   - Automatically signs all multi-ABI split APKs (`arm64-v8a`, `armeabi-v7a`, `x86_64`) with the permanent repository release keystore (`scripts/release.keystore`), ensuring lifetime OTA compatibility.
