### What's New & Improvements in v0.1.4

1. **Progressive Web App (PWA) & Web Manifest Integration**:
   - Added `public/manifest.json` with standalone display modes, orientation, theme branding, and maskable icons.
   - Connected `manifest.json` and bundled `public/app-icon.png` in `index.html` to eliminate 404 touch icon warnings and enable desktop & mobile web installation.

2. **Multi-Platform README & Documentation Suite**:
   - Overhauled root `README.md` with multi-platform download catalogs, build commands, architecture topology, and creator signature.
   - Clarified platform asset coverage across Android (`x86_64`, `arm64`, `arm`), Windows (`NSIS` & portable `ZIP`), macOS (Universal `DMG`), Linux (`DEB`), and iOS (`IPA`).

3. **Synchronized Platform Release**:
   - Automated compilation and publication via GitHub Actions across all 5 operating systems.
