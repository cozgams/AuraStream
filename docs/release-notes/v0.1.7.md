# AuraStream v0.1.7

> **This App Created by AAA**  
> Official release `v0.1.7` (`0.1.7` / Android versionCode `3000107`).

### What's New & Improvements in v0.1.7

1. **Permanent Android Signing Keystore (`scripts/release.keystore`)**:
   - Generated and bundled a permanent 10,000-day RSA 2048 release keystore stamped with creator identity `CN=AAA, OU=Engineering, O=AuraStream`.
   - Updated `.github/workflows/release.yml` so all future release builds across GitHub Actions use this identical keypair by default.
   - Eliminates Android `INSTALL_FAILED_UPDATE_INCOMPATIBLE` signature mismatch errors, ensuring seamless updates and OTA upgrades for all users.

2. **Automated Multi-Platform Builds**:
   - Automated builds across Android (`arm64-v8a`, `armeabi-v7a`, `x86_64`), Windows (`NSIS` & portable `ZIP`), macOS (Universal `DMG`), Linux (`DEB`), and iOS (`IPA`).
