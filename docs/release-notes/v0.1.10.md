# AuraStream v0.1.10

> **This App Created by AAA**  
> Official release `v0.1.10` (`0.1.10` / Android versionCode `3000110`).

### What's New & Improvements in v0.1.10

1. **High-Performance Offline Downloading Engine & Fix for 0% Stall**:
   - Resolved the download stalling issue where episodes were stuck at `0% · 0 B / calculating...`.
   - Added strict 15-second per-request timeouts with automated exponential backoff in `fetchWithRetry` to eliminate permanent socket hangs.
   - Optimized mobile download concurrency (3 threads on Wi-Fi, 2 on cellular), preventing Chrome's per-origin connection pool exhaustion.
   - Added immediate progressive feedback: estimates total episode size upfront so downloads display active progress and speed instantly.
   - Integrated segment recovery queue: transient network errors automatically trigger an automatic retry pass for incomplete segments.

2. **AES-128 Encrypted HLS Offline Playback Support**:
   - Added full `#EXT-X-KEY:METHOD=AES-128` parsing and offline key caching during downloads.
   - Reconstructs local `blob:` encryption key URIs in `getOfflinePlaybackUrl`, enabling zero-data offline playback for encrypted short drama streams even in airplane mode.

3. **Android Large Heap & IndexedDB Memory Optimization**:
   - Replaced memory-intensive `store.getAll()` in `syncOfflineEpisodesFromIndexedDB` with `store.openCursor()`, preventing hundreds of megabytes of binary video buffers from loading into the WebView heap.
   - Added `android:largeHeap="true"` and `android:hardwareAccelerated="true"` to `AndroidManifest.xml` for maximum memory headroom and hardware rendering on Android devices.
   - Guaranteed deterministic `db.close()` across all IndexedDB transaction lifecycles.

4. **Tauri Protocol CORS Preflight (OPTIONS) & Origin Handling**:
   - Added native handling for HTTP `OPTIONS` preflight requests in the `hg://` / `http://hg.localhost` scheme handler returning HTTP 204 No Content with proper CORS headers.
   - Expanded origin whitelist to prevent cross-origin issues on varied Android WebView versions.

5. **Batch Downloader UI Polish & Metadata Title Resolution**:
   - Fixed title propagation in `BatchDownloadSheet`, `Feed`, and `Panels` so batch download banners and notifications always present the formatted drama title.
   - Enhanced progress card formatting in Profile -> Downloads with clean status transitions (`Connecting...`, `Downloading...`, speed, and remaining time).
